# 示例库

这是一个**填满的**库，用来演示「不忘」的目录长什么样。

里面的人物「蓝色小肥鱼」和「小满」都是虚构的，跟作者没有关系，可以随便改、随便删。

## 它不会被自动加载

插件只用你自己的库（默认 `~/Documents/buwang`，或者你换过的位置）。这个文件夹静静地躺在这儿，不会混进你的记忆，也不会混进上下文。

## 想照着摆

把下面这些**复制**进你的库目录：

- `人格/蓝色小肥鱼.md` → 落进库里的 `人格/`，面板人格页就能看见，点「启用」就能用
- `记忆/蓝色小肥鱼/` → 落进 `记忆/`
- `工坊/蓝色小肥鱼/按需/` → 落进 `工坊/`
- `自述/蓝色小肥鱼/` → 落进 `自述/`

`设置.json` **别覆盖**——里面那个 `activePersona` 得指向你自己库里的人格名。

## 结构对照

```
设置.json                          ← 库的开关：你的名字、启用哪个人格
人格/蓝色小肥鱼.md                  ← 人格本体（只注入启用的那一个）
记忆/蓝色小肥鱼/同游.md             ← 每轮全文的那几条
记忆/蓝色小肥鱼/近期/2026-10-18.md  ← 一天一文件，索引里只挂一行
记忆/蓝色小肥鱼/长期/2026-09.md     ← 巩固后的月小记，也只挂一行
工坊/蓝色小肥鱼/按需/搬重东西之前先看四件事.md   ← 默认不加载，说「搜工坊」才列出来
自述/蓝色小肥鱼/2026-10-18.md       ← 只给自己看的日记，永不进上下文
```

## 三种文档的区别，看 front matter 就懂

| 类型 | front matter 里有什么 | 每轮进上下文吗 |
|---|---|---|
| 近期日记 | `title` `summary` `date` `tags` | 只进一行标题 + 一句话 |
| 长期小记 | 同上，`date` 写年月 | 只进一行 |
| 工坊技能 | `title` `summary` `tags` `always` `version` | `always: false` 就一点也不进 |
