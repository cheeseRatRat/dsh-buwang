# 不忘 · 功能介绍

> 一句话：一个**不自动、不联网、数据全在本机**的私人记忆库插件。
> 该记的记得住，不该出现在上下文里的一点都不出现。

---

## 一、它解决的是什么问题

人的记性有偏向。当时觉得天大的事，两个月后只剩一句「好像有过这么回事」；真正要紧的那些，往往连一句都没留下。

模型更直接：上下文一关，刚才聊过的一切就散了——不是不肯记，是没处放。

大部分记忆插件选择**替模型自动召回**：每轮开始前翻一遍库，把「可能相关」的几条塞进上下文。省事，但等于把「什么重要」交给了一个算法。

「不忘」反过来：**它什么都不自动做。**

- 你不说「记住这个」，它一个字都不写
- 你不说「翻一下那天」，它一个字都不读
- 你不说「搜工坊」，那些手艺连名字都不在上下文里

代价是你要开口。好处是：上下文里出现的每一行，都是你同意过的。

## 二、四个分区

| 分区 | 放什么 | 什么时候出现在模型眼前 |
|---|---|---|
| **人格** | 它是谁、怎么说话、什么底线 | 只注入**启用的那一个**，全文，不截断 |
| **记忆** | 同游 / 近期 / 长期，还有只给自己看的「自述」 | 同游全文；近期长期各一行 |
| **工坊** | 可复用的手艺、踩过的坑、做法 | **默认完全不加载**，连名字都不出现 |
| **封存** | 不要了的文档、删掉的人格 | 不出现，随时接回来 |

- **人格**可以有很多个，同一时间只有一个醒着。每个人格一套独立档案，互不串味。
- **删除一个人格**不是真删：整盒（人格 + 记忆 + 工坊）进封存，点「接回来」三块各自归位。
- **共享**是主动的、只读的：默认谁都不共享。

## 三、三层记忆 + 两页私房

| 层 | 怎么长出来的 | 每轮占多少 |
|---|---|---|
| **同游** | 一行一条：定数、约定、偏好（「我不喝冰的」） | 全文 |
| **近期** | 一次总结 = 一条，同一天再总结另起 `-2`、`-3` | 最近 3 天各一行，更早折叠成一行 |
| **长期** | 巩固之后压成一段日子（`2026-09-08~2026-09-30`） | 一行 |
| **自述** | 它自己的日记，用当前人格的口吻写，一页一次，同一小时最多一条 | **从不出现**（不进索引、不进检索） |
| **工坊** | 一条手艺一个文件，常驻 / 按需 | 只有启用的 |

**自述**是给「它自己」的一页。正文顶上写着日期（`2026年10月20日 星期二`），点开任意一页就能就地左右翻：左是更早，右是更晚，按钮上直接写那一页的几点——不用猜方向。

**巩固**什么时候做，永远由你决定。默认只压「今天 + 昨天」以前的，最近两天保留细节。

## 四、七件工具

| 工具 | 干什么 |
|---|---|
| `memory_list` | 列目录，一行一条（标题 / 日期 / 一句话），不返回正文 |
| `memory_recall` | 按日期、标题、关键词翻正文；中文长句也能搜（自动切成 2~4 字的小段） |
| `memory_save` | 写。按内容自动挑落点：定数→同游、当天的事→近期、手艺→工坊、日记→自述 |
| `memory_seal` | 封存一条：撤出索引和检索，文件还在，随时恢复 |
| `memory_consolidate` | 把旧的近期整理成长期。**只列候选，你点头才动** |
| `memory_archive` | 真正落地：日记→长期（带日期区间）；同游→按你指定的行搬去长期，原文一字不改 |
| `memory_workshop` | 开 / 关一条工坊技能。挑中的才注入，办完就关 |

## 五、日常怎么用

几乎不用背命令，开口说话就行：

| 你说 | 它做的事 |
|---|---|
| 「记住这个：我不喝冰的」 | 写成同游里的一行 |
| 「记住今天：把阳台的花搬进屋了」 | 写进今天的近期日记 |
| 「这个做法存进工坊，叫『部署前检查』」 | 存成一条按需技能，默认不加载 |
| 「总结一下今天」 | 写一条记忆 + 一页自述（这一小时写过就跳过） |
| 「翻一下 10 月 19 号」 | 读那天，全文 |
| 「搜工坊」 | 列技能目录，你挑一个，它帮你开 |
| 「封存这条」 | 进封存，随时能恢复 |

面板里也能直接动手：点条目改内容、工坊页「＋ 写一个技能」、自述页就地左右翻、设置里「备份一份」。

## 六、数据与隐私

- **全部是本机明文 Markdown**：没有数据库、没有云同步、没有隐藏格式。用任何编辑器都能改，整个文件夹复制走就是一份完整备份。
- **写不坏**：所有写入先落同目录临时文件再改名，断电或崩溃最多丢「还没落盘的那一篇」，不会把已有记忆写成半截。
- **一键备份**：设置里点一下，整库复制到隔壁 `<库名>-备份-YYYYMMDD-HHMM`；旧备份不删不覆盖，同一分钟再点自动加 `-2`。
- **位置能换**：选文件夹 → 「连文件一起搬」或「只改指向」；旧目录永不自动删。
- **不联网**：除了 DSH 自己的模型调用，插件不发任何请求。

## 七、安装

1. 把仓库文件夹放进 DSH 的插件目录（或用链接安装指向它）
2. 重载插件，侧栏出现「不忘」的图标
3. 第一次打开自动建库：`~/Documents/buwang`，里面有一个叫「默认」的人格和一张空的同游

Windows 路径在 `C:\Users\<你>\Documents\buwang`。想换位置：面板 → 设置 →「换位置…」。

---

## 八、适合谁，不适合谁

**适合**

- 希望「什么被记住」由自己决定，而不是召回算法
- 想要本地、可读、能带走的数据
- 有一个人格长期相处，想让它慢慢记住你

**不适合**

- 想要「什么都不说，它自动记住一切」
- 需要跨设备同步（这个插件刻意只做本机）
- 需要向量检索、知识库式问答（这里放的是日记和关系，不是文档库）

---

## 九、四条铁律

1. **你不开口，它不记。**
2. **你不开口，它不读。**
3. **工坊默认完全不加载。**
4. **人格默认不共享。**
