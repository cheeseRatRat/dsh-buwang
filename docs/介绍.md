# 不忘

> **主动记录的日记与过往，我不会忘记，的私人记忆库**
>
> 日常叫「不忘」。

## 一句话

给 AI 助手一个存在本机的记忆库。**你说记，它才记；你说翻，它才翻。**

## 为什么做

因为聊完就忘太可惜了。

跟助手一起熬过的夜、踩过的坑、想通的事，一切窗口就散了。我想让它记得住这些。

市面上大多记忆插件是自动的：模型觉得有价值就记，每轮自动召回几条塞进去。那很省事，但我不想要——**记什么、什么时候翻，我想自己决定。**

所以就自己写了一个。

## 它是什么

- **三层记忆**：同游（每轮全文，只放一直成立的话）、近期（一天一个文件，索引只挂一行）、长期（月小记，也只挂一行）
- **四个分区**：人格 / 记忆 / 工坊 / 封存
- **人格**可以有很多个，同一时间只启用一个；每个一套独立档案，互不串味
- **工坊**：可复用的做法，默认完全不加载，说「搜工坊」才列出来，挑一个开，用完关
- **封存**：删掉的东西沉在这儿，随时接回来
- 全部是**本机 Markdown**，没有数据库，不上传

## 三条规矩

1. 你不说「记住」，它不写。
2. 你不说「翻一下」，它不读。
3. 你不说「搜工坊」，技能连名字都不在上下文里。

## 不是什么

- 不是知识库：没有向量检索，也没有图谱，找东西靠日期、标题、关键词
- 不自动召回：不会忽然提起你三个月前说的话——这是故意的
- 不跨设备：只在本机，也刻意如此
